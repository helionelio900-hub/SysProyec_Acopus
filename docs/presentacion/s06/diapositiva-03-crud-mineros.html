02 · Registro de mineros

CRUD de mineros:
datos confiables
desde el origen

Antes de registrar una compra, SITRA-ORO valida y persiste la información del minero como base de la trazabilidad del acopio.

POST/api/v1/acopio/mineros
01

Solicitud controlada

El contrato recibe un MineroRequest, sin exponer la entidad de base de datos.

02

Validación de entrada

Documento y nombre obligatorios. Longitudes definidas para documento, teléfono y zona.

03

Persistencia y respuesta

El servicio registra en Oracle y devuelve un MineroResponse con su identificador.

Evidencia mostrada
Registro válido 201 y error de validación 400 ejecutados desde Swagger.

Evidencia de ejecución

Swagger · Oracle · API REST
