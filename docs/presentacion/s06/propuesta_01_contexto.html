Alcance del dominio y arquitectura

SITRA-ORO concentra la cotización, el acopio y la liquidación semanal de oro en un backend REST conectado a Oracle.

Monolito modular

Una aplicación Spring Boot organizada por responsabilidades y verificada con Spring Modulith.

Módulos funcionales

Cotizador, Acopiador G2, Mayorista G1 y Parámetros cubren el flujo operativo actual.

Persistencia real

Oracle de BD2 mediante un perfil de ejecución y configuración externalizada.

Alcance actual
El backend cubre operación, transacciones, consultas, reportes y pruebas. Seguridad JWT: evolución posterior.
