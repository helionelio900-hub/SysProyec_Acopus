2. RESPUESTAS A LAS PREGUNTAS DE DEFENSA (4.5)

  1. ¿Cómo se reproduce la ejecución del backend en otro equipo? Clonando el repositorio y ejecutando .\mvnw.cmd spring-boot:run con Java 21. El wrapper instala Maven automáticamente.
  2. ¿Cómo se configura la conexión sin publicar credenciales? Mediante perfiles application-dev.yml e inyección de variables de entorno en producción.
  3. ¿Qué comprueba el endpoint de verificación? Comprueba que la JVM esté activa y la conexión al pool de base de datos HikariCP funcione correctamente.
  4. ¿Qué diferencia hay entre DTO y entidad persistente? La entidad representa la tabla en Oracle; el DTO desacopla los datos expuestos a la API REST evitando N+1.
  5. ¿Por qué /api/v1/... cuenta como versionado? Porque establece el contrato explícito permitiendo migrar a /api/v2/ en el futuro sin romper aplicaciones existentes.
  6. ¿Qué pasaría si mayorista importara el Repository de acopiador? Rompería la encapsulación. Lo impide Spring Modulith haciendo fallar ModularityTests.

3. ERROR O HALLAZGO TÉCNICO DIAGNOSTICADO

Hallazgo: Riesgo de pérdida de precisión decimal en cálculos financieros si se utilizaba double.

Solución: Se implementó BigDecimal con RoundingMode.HALF_UP a 4 decimales en operaciones intermedias y 2 decimales en desembolsos finales.

4. REFLEXIÓN TÉCNICA BREVE

La ejecución reproducible en diferentes ambientes se logra mediante la estandarización del entorno de ejecución con Java 21 y el uso obligatorio del Maven Wrapper (mvnw), el cual garantiza que todos los desarrolladores compilen exactamente con la misma versión de herramientas sin depender de configuraciones globales del sistema operativo. Además, la separación de la configuración en perfiles (application-dev.yml) inyectando variables de entorno permite migrar el backend entre entornos de desarrollo, pruebas y producción sin modificar una sola línea de código fuente. Finalmente, la verificación estricta de modularidad con Spring Modulith asegura que la arquitectura se mantenga limpia a medida que el proyecto escala.
