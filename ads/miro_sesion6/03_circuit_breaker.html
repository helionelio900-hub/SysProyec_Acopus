Estado ¿Qué significa?
CLOSED Todo funciona normalmente. SITRA-ORO consulta en vivo la cotización spot internacional y las APIs externas.
OPEN Se detectaron fallas repetidas de conexión en La Rinconada y se dejan de enviar solicitudes temporalmente para no colgar la ventanilla.
HALF_OPEN Se realizan algunas pruebas automáticas para comprobar si el servicio de internet o la API externa ya responde.
Circuit Breaker Pattern
Closed
• Servicio saludable
• Peticiones normales
• Reseteo tras éxito
errorRate > umbral
Open
• Falla rápido (Fallback)
• Peticiones cortadas
• Tiempo de espera activo
espera (coolDownPeriod)
Half-Open
• Periodo de prueba con llamadas limitadas
• Éxito: retorna a Closed / Fallo: regresa a Open
miro
