¿Qué es Saga?

Imagina que la tienda vende varias boletas durante el día. BomERP necesita enviar un resumen de esas boletas a SUNAT.

Pero este proceso no termina con un solo envío. Puede suceder lo siguiente:

  1. BomERP reúne las boletas del día.
  2. Envía el resumen a SUNAT.
  3. SUNAT devuelve un número de ticket.
  4. BomERP consulta el estado del ticket.
  5. SUNAT responde si el resumen fue aceptado o rechazado.
¿Y qué sucede si SUNAT rechaza el resumen?
  • BomERP debe revisar el problema, corregirlo y preparar un nuevo resumen.
  • Para coordinar todos estos pasos se utiliza Saga.
